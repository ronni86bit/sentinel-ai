# Risk Communication Checklist
Document ID: RISK-COMMS-2025

## COMMS-1: Message Structure
Every public warning should say what is happening, where, when, who is affected, what action to take, and where to get help.

## COMMS-2: Plain Language
Avoid complex technical language. Use local names for places and landmarks. Use short sentences and repeat the action message.

## COMMS-3: Multi-Channel Communication
Use SMS, WhatsApp groups, local radio, sirens, loudspeakers, ward volunteers, and official social media handles.

## COMMS-4: Rumour Control
The control room should track rumours and issue corrections through trusted local channels.

## COMMS-5: Accessibility
Messages should consider local language, visual formats, voice messages, and persons with disabilities.
